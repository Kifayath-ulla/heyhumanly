Set up HeyHumanly Developer preview

HeyHumanly rewrites your text on your own computer, so your writing never leaves it. It uses Chrome’s built-in model when this computer supports it, or Ollama, a free app that runs AI models locally. It works on its own; you don’t need the Mac app.

Chrome’s built-in model

To use Ollama instead, there are three checks. This page re-checks by itself as you go.

Checking…

  1. 1. Ollama is running

    Install Ollama from ollama.com/download (Mac, Windows or Linux) and open it. Already installed? Open the Ollama app, or run ollama serve in a terminal.

  2. 2. Ollama allows this extension

    Ollama blocks browser extensions until you allow them. This allows only HeyHumanly (), not other extensions or websites.

  3. 3. A writing model is installed

    Pick one. qwen2.5:3b is about 1.9 GB and works with 8 GB of memory. qwen2.5:7b is about 4.7 GB and gives better edits, but needs 16 GB or more.

    Or in a terminal: ollama pull qwen2.5:3b

You’re ready

Select text in any text box and press Alt+Shift+H, or right-click it and choose Tighten with HeyHumanly. You can also paste text into the HeyHumanly button in the toolbar.
