Set up a local AI writing coach on a Mac with Ollama

A local model means your writing is processed on your Mac, not sent to a cloud service. HeyHumanly uses Ollama to run it. This is the whole setup.

  1. Check your Mac

    macOS 14 or later. 16 GB of memory is comfortable for the 7B model (about 4.7 GB). On 8 GB use the 3B model (about 1.9 GB). Allow about 5 GB of free disk.

  2. Install Ollama

    Download it from ollama.com and open it once.

  3. Download a model

    HeyHumanly can do this for you with a progress bar. Or in Terminal run ollama pull qwen2.5:7b (or qwen2.5:3b), then ollama list to confirm.

  4. Open HeyHumanly

    Install it, open it, and it finds the running model automatically. Try pasting a rambling message into Rephrase.

Licenses and honesty notes

Qwen 2.5 7B is Apache-2.0. The 3B model has its own Qwen license. Local models are weaker than the largest cloud models; HeyHumanly's explanations come from rules in the app and your own text, not from guesses by the model. Downloading Ollama and the model needs internet once; after that the coach works offline.
