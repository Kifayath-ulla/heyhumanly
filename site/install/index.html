Install HeyHumanly

Your download should have started. Look in your Downloads folder for HeyHumanly-0.1.0.dmg. We cannot tell if it finished, so use the link below if it did not.

Download again   HeyHumanly-0.1.0.dmg · 5.3 MB · SHA-256 5a88bd761143fd27e4f4fe6e65df47f16f060abdda83ab1eb5c49c0aa68e2c86

  1. Open the DMG

    Double-click HeyHumanly-0.1.0.dmg. If macOS shows a warning here, see below.

  2. Drag to Applications

    Drag HeyHumanly onto the Applications folder in the window. Eject the disk image afterwards.

  3. Open HeyHumanly from Applications

    A short tour opens. It checks for Ollama and the model, and offers buttons to install each.

  4. Allow Accessibility

    Open System Settings → Privacy & Security → Accessibility and switch HeyHumanly on. If you said no, you can turn it on later in the same place; until then the coach window still works with pasted text.

  5. Try your first sentence

    In the tour choose Try an example, or type "Please send me that thung when you have time." in the coach window and press Teach Me. You are ready when you see the corrected sentence and the rule.

If macOS says it cannot check the app

Version 0.1.0 is signed only with an ad-hoc signature and is not notarized by Apple, so macOS may block the first open. This is a known limit of this release, not something to ignore.

Check the file first: in Terminal run shasum -a 256 ~/Downloads/HeyHumanly-0.1.0.dmg and compare it to 5a88bd761143fd27e4f4fe6e65df47f16f060abdda83ab1eb5c49c0aa68e2c86. If it matches and you want to continue, try to open HeyHumanly once, then open System Settings → Privacy & Security, scroll to Security, and choose Open Anyway next to HeyHumanly. You can also read or build the source code yourself. Do not turn off Gatekeeper or other security settings.

Problems

The download did not start

Use the direct link. If your browser blocks it, copy the link into a new tab. The file is hosted on GitHub Releases.

"Ollama isn't running" in the app

Open the Ollama app from Applications, or press Start Ollama in HeyHumanly. HeyHumanly rechecks every few seconds.

The model download stopped

Press Download again; partial downloads resume. Make sure you have about 5 GB free and a working connection. You can also run ollama pull qwen2.5:7b in Terminal.

HeyHumanly cannot read text in other apps

Accessibility is probably off. After installing a new version, remove HeyHumanly from the Accessibility list with the minus button, then add it again.

Which Mac do I have?

Choose the Apple menu → About This Mac. This one download contains both Apple silicon and Intel builds, so you do not need to choose. Apple silicon is tested; Intel is not yet.

Requirements: macOS 14 or later, about 5 GB free disk, 16 GB memory recommended. Back to the home page.
