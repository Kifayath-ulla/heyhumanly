Get better at writing, not just corrected.

HeyHumanly is a free Mac app that watches what you type, marks real mistakes, and teaches you the rule so you stop repeating them. The AI model runs on your Mac.

Version 0.1.0 · macOS 14 or later · 5.3 MB · Free, MIT license · No account

HeyHumanly is for Mac only. You can read about it here, and download it later from a Mac.

What it does

You write in Slack, Safari or any text box. HeyHumanly helps after you stop typing.

Marks mistakes in place

After a short pause, real mistakes get a red wavy underline and wording ideas a dashed one. A small dot shows how many.

Teaches, not just fixes

Click the dot, pick the better version, read the rule in one line, then practise it on a new sentence. Or press ⌃⌥↩ to just fix everything.

Tone and translation

Rewrite a message shorter, warmer, clearer or more professional, or translate it. You see the change before it is pasted.

Keeps your progress

See the mistakes you make most and review short cards made from your own sentences.

Install in four steps

  1. Download and open the DMG

    Download for Mac Open HeyHumanly-0.1.0.dmg from your Downloads folder.

  2. Drag HeyHumanly into Applications

    In the window that opens, drag the leaf icon onto the Applications folder. Then open HeyHumanly from Applications.

  3. Set up the local model (once)

    HeyHumanly uses Ollama, a free app that runs the model on your Mac. The first-run tour shows a Get Ollama button, then a Download button for the model with a progress bar. The model is about 4.7 GB on a 16 GB Mac (1.9 GB on smaller Macs).

  4. Allow Accessibility, then try it

    macOS asks before any app can read a text box. Allow HeyHumanly under System Settings → Privacy & Security → Accessibility. Then type a sentence with a mistake in the coach window or any app, and pause.

About the first open. Version 0.1.0 is not yet notarized by Apple, so macOS may say it cannot check the app for malicious software. Details and the safe way to open it are on the install help page. You can compare the file with the checksum on the release page, or build it yourself from source.

Where your writing goes

Your text is checked by a model on your Mac. HeyHumanly has no account, analytics or tracking, and sends your text only to the Ollama address in its Settings, which is localhost (this Mac) by default.

What it reads

Only the one text box you are typing in, after you pause. Never password fields, password managers, terminals or code editors.

What it stores

Sessions, review cards, your dictionary and settings stay in this app's preferences on your Mac. You can clear them in Settings.

What still uses the internet

Downloading Ollama and the model (done by Ollama and your browser, not by HeyHumanly), and loading this website. HeyHumanly does not check for updates yet.

Read the full privacy page. If you point HeyHumanly at another computer in Settings, it warns you, because then your text leaves this Mac.

Honest limits

  • It works well in Slack, Safari and TextEdit, where it was tested. Chrome, Mail, WhatsApp and other apps are not fully tested.
  • In Slack it shows the dot but cannot underline words, because Slack does not share word positions with other apps.
  • Local models are weaker than the biggest cloud models. The 3B model misses some grammar, and Hindi translation is unreliable.
  • Explanations for long rewrites can take 5 to 10 seconds.
  • Version 0.1.0 is early. There is no automatic update yet: download a new version from this page.

Questions

Is HeyHumanly really free?

Yes. The app is MIT-licensed and free to use. The only costs are your own disk space and the time to download the model. There is no account or subscription.

Does it work offline?

After Ollama and the model are downloaded, the coach runs on your Mac without internet. Downloading them needs internet once.

Do I need Ollama?

Yes. HeyHumanly asks Ollama to run the model. The first-run tour links to the Ollama download and then downloads the model for you with a progress bar. Already have Ollama? HeyHumanly finds it automatically.

Which model does it use?

On a Mac with 12 GB of memory or more it uses Qwen 2.5 7B (Apache-2.0 license, about 4.7 GB). On smaller Macs it uses Qwen 2.5 3B (about 1.9 GB), which has its own Qwen license. You can pick any installed model in Settings.

Why does it need Accessibility permission?

macOS only lets an app read a text box in another app if you allow it. HeyHumanly uses it to read the one box you are typing in, and to paste a fix you accepted. Without it, the coach window still works with text you type or paste into it.

macOS says it cannot verify the app. What do I do?

That is expected for version 0.1.0, which is not notarized by Apple. See the install help page for the steps, and verify the checksum first.

Is it a Grammarly alternative?

It does a similar job of marking mistakes, but its main aim is teaching: it explains the rule and has you practise it, and it runs on a local model instead of a cloud service.

Can I contribute or report a bug?

Yes. The code is on GitHub. Open an issue for bugs. Do not paste private text into public issues.
